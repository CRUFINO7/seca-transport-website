# UI/UX Pro Max Skill — CLAUDE.md

## Project: Antigravity Kit — AI-Powered Design Intelligence Toolkit

This skill provides searchable databases of UI styles, color palettes, font pairings, chart types, and UX guidelines.

### Design Principles
- Use modern, clean layouts with strong visual hierarchy
- Apply consistent spacing, typography, and color systems
- Prioritize mobile-first responsive design
- Use professional, accessible color contrasts (WCAG AA minimum)
- Implement smooth transitions and micro-interactions
- Follow established UX patterns for navigation, CTAs, and forms

### Stack: html-tailwind (default — adapted for pure HTML/CSS/JS)
- Use CSS custom properties (variables) for theming
- Prefer CSS Grid and Flexbox for layouts
- Use semantic HTML5 elements
- Implement smooth scroll and intersection observers for animations
- No external frameworks or npm dependencies

### Color System
- Dark navy backgrounds create professionalism and trust
- Orange/amber accents drive attention and CTAs
- White/light grays for text and card backgrounds
- Consistent use of shadows and borders

### Typography
- Use system fonts or Google Fonts (loaded via link tag, no npm)
- Strong heading hierarchy (h1–h4)
- Comfortable line-height (1.6–1.8 for body text)
- Clear font-weight contrast between headings and body

### UX Guidelines
- Navigation: sticky header with mobile hamburger menu
- Hero sections: full-viewport with clear value proposition
- CTAs: prominent, contrasting, action-oriented text
- Forms: clear labels, validation feedback, accessible inputs
- Footer: comprehensive with links, contact, legal pages
- Animations: subtle, performance-conscious (CSS transitions preferred)
